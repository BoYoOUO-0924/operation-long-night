# 過場動畫

## 怎麼用
1. 在 `levels/cutscenes/` 新增一個 `<名稱>.json`。
2. 執行 `python tools/build_level.py`。它會把檔案複製到資料包 `data/ln/cutscenes/`，並依照 `levels/ch05_trial.json` 的 speakers 自動幫字幕填上名字顏色。
3. 把資料包同步到伺服器，然後 `/reload`。
4. 播放：`/lnhud cutscene @a ln:<名稱>`；中止：`/lnhud cutscene @a stop`

## 播放時會發生什麼
- 鏡頭沿著設定的路線移動，上下黑邊滑入，HUD、手、名牌全部隱藏，玩家不能移動。
- 預設播放期間玩家無敵，可以用 `"protect": false` 關掉。
- 伺服器照時間執行 `commands`，例如傳送 NPC、播音效、開始下一段劇情。
- 播完淡出，鏡頭回到玩家身上。

## 格式
```json
{
  "letterbox": 0.11,          // 上下黑邊各佔畫面高度的比例，0 = 不要黑邊
  "fade_in": 20,              // 開頭從黑畫面淡入幾 tick（20 tick = 1 秒）
  "fade_out": 20,             // 結尾淡出到黑畫面幾 tick
  "protect": true,            // 播放期間玩家無敵
  "camera": [                 // 鏡頭關鍵格，依時間排序
    {"t": 0,   "pos": [154, 153, 1003], "look_at": [107, 140, 965], "fov": 60},
    {"t": 100, "pos": [141, 142, 976],  "look_at": [133, 137, 961], "fov": 70},
    {"t": 100, "pos": [102, 151, 959],  "look_at": [88, 143, 959], "cut": true}
  ],
  "subtitles": [
    {"at": 20, "dur": 70, "who": "狐狸", "text": "МЕТЕОСТАНЦИЯ №7……"}
  ],
  "commands": [
    {"at": 0, "run": "playsound minecraft:item.elytra.flying ambient @a 107 145 965 0.5 0.6"}
  ]
}
```

### 鏡頭關鍵格
| 欄位 | 說明 |
|---|---|
| `t` | 第幾 tick |
| `pos` | 鏡頭位置 |
| `look_at` | 看向哪個點。前後兩格都有 `look_at` 時，鏡頭移動中會一直盯著（注視點也會跟著移動） |
| `yaw`、`pitch` | 沒有 `look_at` 時用角度指定（yaw 0 = 南，pitch 正 = 往下看） |
| `roll` | 鏡頭左右傾斜的角度，做手持晃動或傾斜鏡頭用 |
| `fov` | 視角大小，越小越像望遠鏡頭，預設 70 |
| `cut` | `true` = 從這一格開始是新的鏡頭，直接切過去、不滑動 |
| `ease` | `"linear"` = 等速；不寫 = 緩進緩出 |
| `handheld` | 手持晃動強度（0 = 穩定，0.9 ≈ 跟拍的手持感），套用到這格之後，直到下一個有寫的格 |

- `"pos": "player"`：這一格用玩家自己的眼睛位置和視角，拿來做「衝進玩家眼睛、交還操作」的結尾。
- `"fov": "player"`：用玩家自己的視角大小。

- 路線用平滑曲線串起同一個鏡頭裡的所有關鍵格。要做環繞鏡頭，就在圓周上放三、四格。
- 整段過場的長度，取最後一個關鍵格、最後一句字幕結束、最後一個指令三者中最晚的時間。

### 其他欄位
| 欄位 | 說明 |
|---|---|
| `shakes` | 畫面震動：`[{"at": 210, "dur": 5, "amp": 1.6}]`，踹門、重低音這種重拍用 |
| `titles` | 畫面中央的大標題：`[{"at": 30, "dur": 90, "text": "第五章　寒霜陷阱", "sub": "零下四十度"}]` |
| `frost_after` | 播完後畫面邊緣結霜幾 tick（冰霜外框慢慢退掉），0 = 不要 |
| `freeze` | 這些 tag 的 NPC 在過場期間不跑 AI（不亂走、不開槍），播完自動恢復，例如 `["ln_ally"]` |
| `moves` | NPC 走位：`{"at": 220, "dur": 50, "tag": "ln_tank", "path": [[x,y,z], ...]}`，沿路徑等速走完、面向前進方向，預設自動貼地（`"ground": false` 關掉） |

角色動作用指令播：`/lnhud anim @e[tag=ln_tank] kick`、`stop` 停止。動作檔在 `mod/src/main/resources/assets/lnai/player_animation/`，由 `tools/build_anims.py` 產生（kick、support、limp、wrist_tap、shiver、point、guard）。

第五章開頭 `ch05_intro.json` 是 `tools/make_ch05_intro.py` 產生的，要改這段請改腳本再重跑。

### 字幕
- `at`：第幾 tick 出現；`dur`：顯示幾 tick（預設 60）。
- `who`：說話的人；`text`：台詞；`color`：可省略，`build_level.py` 會自動填。

## 限制
- 鏡頭只能拍玩家附近已載入的區域（大約視野距離內），太遠的地方會是空的。
- 過場不會暫停戰鬥。需要時要用 `commands` 停止敵人生成，或讓 NPC 先站好。
- 還不能跳過過場。
- `/lnhud cutscene @a stop` 中止時，被 `freeze` 的 NPC 不會自動恢復 AI。
