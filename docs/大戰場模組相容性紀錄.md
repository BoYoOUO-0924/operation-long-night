# Minecraft 大戰場專案：模組相容性紀錄

> 最後更新：2026-11-19
> 資料來源：CurseForge / Modrinth 網頁搜尋（尚未實際安裝驗證）
> 「相容」只代表**版本與載入器對得上**；模組之間實際會不會衝突，要裝起來測過才知道。

## 專案目標
- 類似現代軍事 FPS 的大戰場玩法（原創，不抄既有遊戲的名稱、地圖、素材）
- 寫實槍械 + 載具 + 大量 NPC 補位
- 第一階段：只做槍械，地圖先用超平坦
- 技術路線：模組（C 方案）優先，不排斥外掛（B）

## 使用者電腦現況
- 已安裝 Minecraft 26.2、NeoForge 26.2、Fabric 26.2
- 啟動器：CurseForge、Prism Launcher
- 系統 Java 為 Java 8（太舊；單人遊玩由啟動器自帶的 Java 處理，架伺服器時需另外安裝）

| 版本 / 載入器 | 槍械 | 載具 | 持槍 NPC | NPC 開載具 | 地圖工具 | 評價 |
|---|---|---|---|---|---|---|
| **1.20.1 Forge** | ✅ TaCZ 官方版 | ✅ Superb Warfare 等多款 | ✅ 多款 | ✅ Combined Arms | ⚠️ WorldEdit 舊版（待確認） | ⭐ **生態最完整，建議** |

**結論：選 1.20.1 Forge。** 槍、載具、持槍 NPC、NPC 開載具這四塊，目前只有這個版本全部都有。

## 一、槍械

| 模組 | 版本 | 說明 |
|---|---|---|
| **TaCZ（Timeless and Classics Zero）** | 1.20.1 Forge（官方，1.1.8-hotfix，2026-05） | 寫實度最高：3D 槍模、開鏡、後座力、換彈動畫、配件、槍包。**主要選擇** |
| TaCZ 非官方移植版 | 1.21.1 NeoForge（1.1.8-hotfix-r6，2026-07） | 非原作者維護 |
| Vic's Point Blank | 1.20.1 / 1.21.1 / 26.1.2 NeoForge | 備案；寫實度稍低 |

## 二、載具

| 模組 | 版本 | 說明 |
|---|---|---|
| **Superb Warfare（SBW）** | 1.20.1 Forge（需 Forge 47.2.0+）/ 1.21.1 NeoForge，0.8.9.x | 坦克、攻擊直升機、戰機、火砲等，在載具組裝台製作。大多數載具靠 FE 電力驅動，需要準備充電方式。⚠️ SBW 本身也有槍，可能跟 TaCZ 重複，需要調整設定或用指令限制取得 |
| SBW 擴充：AshVehicle、Vintage Vehicle Pack、Frontline Combat Pack | 依附 SBW | 更多載具 |
| Immersive Vehicles（MTS） | 1.20.1 Forge（24.0.0，2026-04） | 偏汽車與飛機，較不適合軍事 |
| Vehicle Fleet | 1.20.1 Forge（需 GeckoLib 4） | 直升機操控較寫實 |
| Flan's Mod Ultimate 2 | 1.20.1 Forge | 槍和載具一體，跟 TaCZ 有功能重疊 |

**建議：SBW**（目前最多人用，也有 NPC 開載具的整合模組）

## 三、NPC（持槍士兵）

| 模組 | 版本 | 說明 |
|---|---|---|
| **TaCZ: Simple Enemy** | 1.20.1 Forge（0.1.5-beta，2026-06） | 生成拿 TaCZ 槍的敵人。**搭配 Combined Arms 可以讓 NPC 開 SBW 載具** |
| TACZ: Npcs | 1.20.1 Forge | 約 160 萬下載，最多人用 |
| Project TacZ NPCs | 1.20.1 Forge | 另一款持槍 NPC |
| Villager Recruits + **Tacz:Recruits** | 1.20.1 Forge | 可招募、帶隊、下指令的士兵，會自動使用 TaCZ 槍。適合「NPC 隊友補位」 |
| TACZ Recruits（另一個專案） | 1.20.1 Forge，1.0 版 | 作者自稱很早期、有 bug，**不建議** |
| CNPC Tacz Fire | 搭配 Custom NPCs | 讓 Custom NPCs 使用 TaCZ 槍，可做劇情 NPC |

## 四、NPC × 載具整合

| 模組 | 版本 | 說明 |
|---|---|---|
| **[TaCZ/SBW] Combined Arms** | Forge / NeoForge（1.21.1 檔案日期為 2026-10） | 讓 Simple Enemy 的 NPC 搭乘或跟著 SBW 載具一起生成。⚠️ 需要確認 1.20.1 Forge 版的檔案是否存在 |

## 五、地圖製作工具

| 模組 | 版本 | 說明 |
|---|---|---|
| WorldEdit | 7.2.x 應支援 1.20.1 Forge（**待確認**）；7.3.1 起改為 NeoForge 專用 | 大範圍放置、複製、貼上建築 |

## 測試環境（2026-11-19 建立）
- Prism 環境：「大戰場測試」（`%APPDATA%\PrismLauncher\instances\大戰場測試`）
- Minecraft 1.20.1 + Forge 47.4.16 + Java 17（Prism 已有的 java-runtime-gamma）
- 記憶體：6 GB（電腦總共 32 GB）
- 模組：`tacz-1.20.1-1.1.8-hotfix2.jar`（從 Modrinth 下載，已核對 SHA512）
  - 選 1.1.8-hotfix2 而不選 1.2.0：NPC 擴充模組大多以 1.1.8 為基礎開發
- 模組：`tacznpcs-2.1.0-1.20.1.jar`（[TACZ] NPCs，從 Modrinth 下載，已核對 SHA512；2026-11-19 加入）
  - 用 `tacznpc_factions.json` 設定陣營、`tacznpc_loadouts.json` 設定裝備，第一次啟動後才會產生這兩個檔案
- 測試世界「新的世界」裡的資料包 `battle_test`：`/function battle:spawn_test`（生成 10 對 10）、`battle:wave`（再加 5 對 5）、`battle:count`（顯示數量）、`battle:clear`（全部清除）
- 已確認：TaCZ 單獨啟動、試射正常；預設 villagers / illagers NPC 會互打（2026-11-19）
- 紅藍隊設定（2026-11-19）：原始設定檔備份在 `config/backup-original/`
  - 陣營：紅隊攻擊藍隊、玩家、怪物；藍隊與玩家同陣營。限制：所有玩家都算同一陣營，玩家沒辦法各自選隊
  - 兵種與槍械（裝備定義在資料包 `battle:npc/<隊伍>_<兵種>`，穿染色皮甲、死亡不掉落）：

    | 兵種 | 紅隊（東） | 藍隊（西） |
    |---|---|---|
    | 突擊 assault | AK47 / 81 式 | M4A1 / HK416D |
    | 支援 support | RPK | M249 |
    | 狙擊 sniper | AI AWP | M700 |
    | 近戰 cqb | UZI | MP5A5 / M870 |
  - 手動生成單一 NPC：`/summon tacznpcs:npc ~ ~ ~ {template:"red_sniper"}`
- 你原本的「霁月千秋」環境（1.20.1 Forge，121 個模組）已經有 GeckoLib 和 Custom NPCs 非官方版，之後可以參考
