## 常用指令（遊戲內）
| 指令 | 作用 |
|---|---|
| `/function ln:view_station` | 傳送到可以看到整座氣象站的位置（創造模式） |
| `/function ln:ch05/start` | 開始第五章試做關卡 |
| `/function ln:ch05/stop` | 中止關卡，回到創造模式 |
| `/function ln_tool:help` | 標記工具箱說明 |
