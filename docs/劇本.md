# 《代號：長夜》劇本大綱

原始大綱由 Gemini 撰寫，之後依技術限制修訂（2026-11-19）。第五章的台詞已實際做進試玩版，以 `levels/ch05_trial.json` 為準。

## 角色

| 角色 | 身分 | 備註 |
|---|---|---|
| 玩家（獵犬 1～4） | 獵犬小隊隊員 | 1～4 位真人玩家，人數不足由藍隊 NPC 補位 |
| 白鴉 | 狙擊手 | 劇情 NPC，最後唯一倖存的隊友 |
| 戰車 | 重火力手 | 劇情 NPC，脾氣火爆，第七章犧牲 |
| 狐狸 | 電子戰專家 | 劇情 NPC，第七章犧牲 |
| 情報官 | 第三章救出的倖存者 | 身上被植入追蹤器，是敵軍放出的誘餌；最後為贖罪犧牲 |
| 守夜人 | 敵方指揮官 | 透過無線電嘲諷小隊，第八章最終對決 |

## 各章

### 第一章：雷霆空降（海岸防空陣地）
- **開場：** 3 分鐘機艙序章。玩家在運輸機裡和三位隊友各聊一次（白鴉擦槍、戰車講冷笑話、狐狸調設備），同時當作操作教學。
- **任務：** 在離地約 120 格跳出機艙，跳傘降落敵軍「黑石海岸砲台」，15 分鐘內炸毀三座雷達，替友軍艦隊掃清盲區。

### 第二章：海岸線的葬禮（懸崖觀測站）
- **劇情：** 玩家用望遠鏡標記敵軍「電磁軌道巨砲」的位置。巨砲齊射，三分鐘內擊沉友軍艦隊，下一輪轟向懸崖，小隊衝刺逃離崩塌的觀測站。
- **轉折：** 指揮部斷訊前下達最後命令：「啟動長夜預案，任何倖存單位都要設法摧毀巨砲，第二波艦隊 72 小時後抵達。」
- **伏筆：** 撤離時狐狸的掃描器被砲擊震壞。

### 第三章：溺水之城（半淹沒現代都市）
- **玩法：** 潛行。無人機探照燈光圈踩進去才會被發現，被發現也只是觸發戰鬥。
- **劇情：** 在安全屋救出情報官，取得關閉超武的「物理密鑰」。隊友問他為什麼只有他活下來，他支吾其詞。

### 第四章：鋼鐵狂飆（峽谷裝甲列車）
1. 在補給站奪取一列敵軍裝甲列車（地面戰）。
2. 列車穿越隧道（重複移動牆面和燈光），過場鏡頭交代峽谷追逐，敵軍皮卡車隊與直升機追擊。
3. 列車被直升機逼停在峽谷鐵橋上，大型攻防戰。
- **結尾（銜接第五章）：** 列車在雪山腳下因軌道被炸而翻覆脫軌，小隊在暴風雪中徒步求生。

### 第五章：寒霜陷阱（極寒山區氣象站）← 試玩版
1. **步行接近**：翻車後在暴風雪中前進，發現山腰的蘇聯氣象站。情報官走不動，戰車說「走不動就用爬的」。
2. **抵達**：狐狸認出「МЕТЕОСТАНЦИЯ №7」，地熱鍋爐還在運轉。戰車押著情報官進無線電室，白鴉上瞭望塔。玩家去車庫找零件箱。
3. **揭露**：
   - 狐狸修好掃描器，一開機就發現追蹤器訊號在情報官身上。
   - 戰車要斃了他，情報官喊出「沒有我的視網膜和聲紋，就進不了總控室」。
   - 守夜人透過無線電說：「獵犬小隊，晚安……好好享受最後的溫暖吧。」
4. **防守**：撐到敵軍兵力耗盡。中途發電機故障，要去南邊小屋重新啟動。最後是皮卡和迫擊砲的主攻。
5. **結尾**：敵軍後撤重新部署。戰車對情報官說「你的命現在是我的」。狐狸：「方舟的入口就在這座山底下。下一站——地下。」

### 第六章：深淵方舟（地下核掩體）
- **玩法：** 走廊 CQB → 垂降巨大豎井 → 停電區（只靠槍燈）→ 通風管繞背 → 反應爐大廳。
- **劇情：** 在裝甲主門前，戰車用槍抵著情報官的頭，逼他完成視網膜與聲紋認證。

### 第七章：黎明前的最後防線（衛星發射井核心）
- **玩法：** 系統上傳期間防守 6 分鐘，分三段後撤：外圍閘門 → 中層機房 → 控制室。
- **犧牲（以過場呈現）：**
  - 戰車：從外側關上防爆閘門，自己留在外面用重機槍擋敵軍。
  - 情報官：用雙手接住高壓斷線贖罪。
  - 狐狸：護住終端機，撐到上傳 100%。

### 第八章：破曉（海岸高地）
- **最終對決：** 守夜人搭武裝直升機追來，玩家用雷射標定器引導已被駭入的巨砲把他擊落。
- **結局：** 玩家和白鴉走出通風口，看著友軍第二波艦隊與戰機在朝陽下飛過。把戰車、狐狸的狗牌掛在插在雪地的步槍上，敬禮。全劇終。
