# Operation: Long Night（代號：長夜）

Minecraft 1.20.1 Forge 原創故事地圖專案（1～4 人合作）。

## 資料夾
- `docs/`：劇本、設計文件、模組相容性紀錄、進度表
- `datapack/`：故事模式資料包原始檔（部署到伺服器世界）
- `generators/`：Python 建築與地形生成腳本
- `tools/`：輔助工具（RCON 指令、部署、備份）
- `server/`：本機 Forge 伺服器（不進 git）
- `backups/`：世界備份（不進 git）

## 技術組合
- Minecraft 1.20.1 + Forge 47.4.16
- TaCZ 1.1.8-hotfix2（槍械）
- [TACZ] NPCs 2.1.0（持槍 NPC）
